# Moonstone 0.7.0

This release consolidates runtime, store, workspace, installation, and
file-registry commands. Scripts using the previous spellings need the
substitutions below.

## Corrected publication

The original October 16 publication contained only the registry portion of the
intended 0.7 CLI changes. The corrected publication keeps version 0.7.0 and
rebuilds every platform artifact from the complete implementation. Its build
label is `standalone-reissue.1`; the release manifest records revision 1 and the
source commit. The original commit and artifacts remain available under the
archive release `archive/v0.7.0-original-20261016`.

Existing standalone installations should reinstall 0.7.0 using the command
below. Homebrew publishes revision 1, allowing `brew upgrade moonstone` to pick
up the correction. Pull Docker images again; existing containers and pinned
image digests do not update automatically.

## Migrate from 0.6

| Before | 0.7 |
| --- | --- |
| `registry create PATH NAME` | `registry init --file PATH --name NAME` |
| `registry push PATH --descriptor FILE --blob ARCHIVE` | `registry --file PATH publish --descriptor FILE --artifact ARCHIVE` |
| `registry sync PATH` | `registry --file PATH sync` |
| `registry NAME: index rebuild` | `registry NAME: sync` |
| `registry NAME: package delete PACKAGE@VERSION` | `registry NAME: remove PACKAGE@VERSION` |
| `registry purge PATH --p-name PACKAGE --version VERSION` | `registry --file PATH remove PACKAGE@VERSION` |
| `registry NAME: settings show` | `registry NAME: doctor` for health; inspect `registry.toml` for raw metadata |

Connection management remains `registry add`, `registry list`, and
`registry remove NAME`. A trailing colon selects a registry to operate on:
`registry NAME: remove PACKAGE@VERSION` removes a published version, while
`registry remove NAME` removes the project's connection.

Publication, sync, and removal preserve the registry's name and id. Removal
requires an explicit version, rejects unknown flags, and rejects descriptor
paths that escape the selected registry. It removes the descriptor and rebuilds
the indexes; it does not garbage-collect shared blobs.

Target authoring supports local file registries. Authenticated remote publication
is not implemented by these commands.

## Other fixes

- CLI help describes implemented flags and output formats more accurately.
- `moon env --shell` rejects unsupported shells before environment discovery.
  Supported shells are Bash, Zsh, and Fish.
- `cache manifest clear all` and `refresh all` accept the explicit `all` source.



## Runtime, store, workspace, and lifecycle consolidation

| Previous command | Replacement |
| --- | --- |
| `interpreter install lua@5.4` | `add --global lua@5.4` |
| `interpreter set lua@5.4` | `set lua@5.4` |
| `interpreter set --global lua@5.4` | `set --global lua@5.4` |
| `interpreter remove lua@VERSION` | `remove --global lua@VERSION` |
| `interpreter list` | `store list --interpreters` |
| `interpreter current` / `interpreter path` | `env` / `store path` |
| `remove --global --link NAME` | `remove --global link:NAME` |
| `store query --by-package NAME` | `store list --by-package NAME` |
| `store query NAME` / `store list --search NAME` | `store list --query NAME` |
| `index vacuum` | `store prune --compact` |
| `orbit sync NAME` | `--orbit NAME sync` |
| `orbit exec NAME -- COMMAND` | `--orbit NAME exec -- COMMAND` |
| `orbit run NAME -- SCRIPT` | `--orbit NAME run SCRIPT` |
| `orbit sync` | `sync --all` (now includes the root first) |
| `self install --latest` | `self update` |

Project linked dependencies use ordinary `remove NAME`. Unregistering a global
live link preserves its source. Runtime removal refuses referenced artifacts;
`set` explicitly selects a replacement instead of choosing a fallback.

Store listing keeps detailed provenance in STATUS event data and ends with a
count-bearing RESULT. It no longer returns the old query command's bare JSON
array. Exact selectors can be combined with structured filters. A fuzzy query
uses the same matching rule with or without a usable metadata index.

`sync --all` processes the root then direct children in declaration order,
forwards all sync flags, stops on failure, and does not roll back completed
projects. Its JSON output has one final workspace completion. The runtime-only
`--locked` regression is fixed. `--orbit` selects declared names; use `-C` for
arbitrary paths. Shell completion carries the selected project into tool lookup.

`self update` previews the current installer channel's latest-release command;
`self install --version` selects an exact release. `--apply` remains POSIX-only.
Uninstall removes the executable and shims, preserving data by default. Explicit
`--purge-data` lists and removes managed paths, with safety checks. Windows
schedules executable deletion after exit. Package-manager builds remain owned
by their package manager.

See [command workflows](../CLI_WORKFLOWS.md) for scope and examples. `env`,
`exec`, and `run` retain their distinct roles; no activation command is added.

## Upgrade

```sh
moon self install --version 0.7.0 --apply
moon version
# Moonstone v0.7.0 (standalone-reissue.1)
```

Use your package manager for installations it manages. Lockfiles and dependency
specifications do not need migration for this command change.
