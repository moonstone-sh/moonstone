# Moonstone 0.7.1

Windows script launchers preserve arguments and exit status, with native and Wine lifecycle checks. Windows LuaRocks builds now produce loadable `.dll` modules; environment projection also exposes existing PE modules stored with a `.so` suffix under the correct `.dll` name.

Build integrations can hash files through `moon artifact hash`, and `moon store list --json` includes indexed module provisions for exporters working with copied environments.

Release certification covers cancellation and descendant cleanup, native package lifecycles, and the candidate release archives before publication.
