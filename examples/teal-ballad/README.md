# Teal × Cyan × Moonstone × Ballad Example

A modern, typed Teal CLI application using [`argparse`](https://github.com/luarocks/argparse) for command-line parsing, compiled via **Cyan**, and packaged deterministically into a standalone executable layout using **Ballad**.

## Conceptual Responsibility Division

* **Moonstone**: Owns the hermetic environment, locking exact dependencies (`cyan`, `argparse`, `ballad`) and projecting executables into `.moonstone/env/`.
* **Cyan**: Owns the Teal build lifecycle, reading `tlconfig.lua`, static checking (`cyan check`), compilation (`cyan build` from `src/*.tl` to `build/*.lua`), and execution (`cyan run`).
* **Ballad**: Owns final distribution packaging, consuming intermediate Lua artifacts in `build/` and runtime dependencies to produce a self-contained executable in `dist/`.

## Directory Separation

* `src/`: Typed Teal source code (`src/*.tl`).
* `build/`: Intermediate compiled Lua files generated by Cyan (`build/*.lua`).
* `dist/`: Standalone binary distribution directory produced by Ballad.

## Teal Type Declarations (`.d.tl`)

Libraries like `argparse` have official community type definitions available in the [`teal-language/teal-types`](https://github.com/teal-language/teal-types) repository (e.g. `types/argparse/argparse.d.tl`).

## Project Structure

```text
examples/teal-ballad/
├── moonstone.toml   # Project manifest (Cyan tool, argparse runtime, & Ballad tool)
├── tlconfig.lua     # Cyan / Teal compiler configuration (build_dir = "build")
├── partiture.lua    # Ballad build & export pipeline specification
├── src/
│   ├── cli.tl       # CLI interface definition using argparse
│   └── main.tl      # Main entry point
└── README.md
```

## Quick Start

### 1. Install & Sync Dependencies

Resolve `cyan`, `argparse`, and `moonstone/ballad` into your hermetic `.moonstone/env/`:

```bash
moon sync
```

### 2. Type Check Teal Code

Run static type checking across your `.tl` sources via Cyan:

```bash
moon run check
```

### 3. Run Development Code

Execute the entry point directly via Cyan:

```bash
moon run run -- --name Moonstone --greeting Welcome --count 3 --verbose
```

### 4. Build Intermediate Lua & Package Standalone Release Artifacts

Compile `src/*.tl` to `build/*.lua` via Cyan, then export a self-contained executable application layout into `./dist/`:

```bash
moon run export
```

Or run Ballad directly via `moon exec`:

```bash
moon exec ballad play partiture.lua
```

### 5. Run the Exported Executable

```bash
./dist/bin/teal-example --name "Baaaa ♫" --count 2
```
